01 / 开源作品

以 Agent Hub 为起点

三个公开入口分别承担通用协作、方法 Skill 和离线评估任务组织。

主要项目

Agent Hub

本机单用户多 Agent 协作界面，提供直接执行、主 Agent 编排和有界共同研讨。通过配置云端模型 API 使用；本页的云端路线无需部署本地大模型。

Python · MIT · 公开源码与使用文档

02 / 云端模型实践

DeepSeek 网页摘要指令冲突：一组对照

使用合成资料测试摘要任务中出现的冲突指令，保留完整输入、网页回答与截图。网页操作由自动化执行；三次尝试中一次输入被排除，另两次组成一组有效对照。

这组观察未支持预定的指令偏离。单组结果的结论范围限于所记录的输入与网页会话。
